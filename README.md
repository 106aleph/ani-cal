# アニメ配信カレンダー

[しょぼいカレンダー](https://cal.syoboi.jp/) から新作アニメの配信予定を取得し、媒体を選んで登録 → カレンダーで確認 → 1話ごとに視聴記録できるセルフホストアプリです（FastAPI + SQLite、1コンテナ）。

## 必要な環境

- Linux ホスト（動作確認: Debian 13）
- Docker と Docker Compose
- Tailscale（管理画面で MagicDNS と HTTPS Certificates を有効化）
- `cal.syoboi.jp` への HTTPS 通信

## セットアップ

```bash
cp .env.example .env              # 必要なら編集
docker compose up -d --build
docker compose logs -f            # 初回取得は数分
sudo tailscale serve --bg 8000    # APP_PORT を変えた場合はその番号
```

`https://<ホスト名>.<tailnet名>.ts.net/` を tailnet 内の端末で開きます。PWA として、ブラウザからホーム画面やデスクトップにインストールできます。

- コンテナは `127.0.0.1` にしか公開しません。アクセスは `tailscale serve` 経由のみです。
- 認証は持たず、Tailscale の ACL で制御する前提です。ルート `/` 前提のため、サブパス公開（`--set-path`）は非対応です。他のサービスと併用するときは `--https=8443` など別ポートにしてください。

## 画面

| 画面 | できること |
|---|---|
| カレンダー | 月／週（時間軸・現在時刻の線つき）／リスト（月ごと）。視聴チェック、クリックで編集、深夜帯の「25:30」表記切替 |
| 新作一覧 | 媒体ごとの第1話日時つき一覧。媒体チップをクリックで登録。時期・媒体・配信系・未登録・タイトルで絞り込み |
| 登録作品 | 話数一覧、視聴チェック、話の追加・編集・削除、媒体の変更、タイトル／媒体名の上書き、間隔指定での話の作成、一括視聴、ICS 出力 |
| 視聴済み | 全話視聴した作品の置き場。登録作品の「視聴済みに移す」（全話視聴済みのときだけ押せる）で移動、「登録作品に戻す」で復帰。カレンダー・未視聴一覧・ICS には出ない。新しい話が追加されると自動で登録作品に戻る |
| ログ | 取得履歴（日時・種別・範囲・結果・所要時間・件数）。最新500件 |

- 通知: 右上の「通知」で、配信開始の N 分前に端末へ通知（Web Push）。分数は端末ごとに設定、テスト通知あり。詳細は「通知」の節。
- 編集した話は「修正済」になり、再取得で上書きされません（「取得値に戻す」可）。削除した話は再取得でも復活しません（「復元」可）。
- 取得データにない作品は「手動で作品を追加」、先の話数が未登録の作品は「間隔で話を作成」（予測。実データが入ると置き換わり、視聴記録は保持）で扱えます。
- ICS 購読: `/calendar.ics`（`?unwatched_only=true` で未視聴のみ）。tailnet 外のサービスからは取得できません。

## 取得の仕組み

公式 API（`db.php`）を、[bot向けルール](https://docs.cal.syoboi.jp/rule/bot/)に沿って使います。

| 種類 | タイミング | 内容 |
|---|---|---|
| 初回 | 最初の取得 | 60日前〜120日先を2日ずつ取得（数分） |
| 定期・起動時・今すぐ | **6時間ごと**（10分おきに確認し、前回成功から6時間以上で実行） | 前回以降の更新分だけを**差分取得** |
| 期間指定 | 画面右上のボタン（最大180日。片方の日付を選ぶともう片方が自動入力） | 指定期間を取得。差分の基準は進めない |

- 定期取得の間隔は `.env` の `SYNC_INTERVAL_HOURS`（既定6。`0` で自動取得なし）。差分取得なので、1回は数リクエスト、1日で十数リクエスト程度です。起動時は、前回成功から6時間以上たっているときだけ取得します。
- 取得中は右上の「中断」で止められます。取得済みの分は保存され、中断は失敗として数えません。
- リクエストは直列・1.5秒間隔。`429`/`503` は `Retry-After` に従って待ち、再試行は5回まで（待ち時間は倍々＋乱数）。待ちが5分を超える場合は待たずに取得を失敗として終えます（`SYOBOI_MAX_WAIT_SEC`）。
- 自動取得が連続5回失敗すると自動取得を停止します（画面に表示）。「今すぐ取得」で成功すると再開します。
- 登録作品への反映は、取得成功時の最後に行います（「定期取得で自動更新」がオンの作品のみ）。
- 放送開始が古い作品や取りこぼしは、「期間指定」で取り直してください。
- **新作**の判定: カテゴリがアニメで、放送開始が今月の3ヶ月前〜6ヶ月後。放送中なら12ヶ月前までを含みます。**配信系**: チャンネルグループ名に「ネット/インターネット/配信/web」を含む媒体（`NET_GROUP_IDS` で指定も可）。
- 各設定は `.env`（項目は `.env.example`）。User-Agent は `AnimeCalendar/1.0` で、公開できる案内ページがあれば `SYOBOI_UA_URL` にURLを設定します（任意）。

## 通知

右上の「通知」→「通知を有効にする」で、カレンダーに登録した作品の**未視聴の話**が、開始の N 分前（既定10分、0〜1440）に、アプリを開いていなくても届きます。視聴済みに移した作品・非表示の話は対象外です。

- 設定は端末（ブラウザ）ごと。通知を止める／分数の変更／テスト通知も同じ画面から行います。
- 通知には HTTPS（`tailscale serve`）が必要です。iPhone / iPad は、ホーム画面に追加したアプリ（iOS 16.4 以降）から有効にしてください。
- サーバーが Google / Mozilla / Apple / Microsoft の Push サービスへ HTTPS で送信します（コンテナから外向き通信が必要。tailnet 内で完結はしません）。送信先はこの4つに限定しています。
- 通知は30秒おきに確認して送ります。開始後3分までは送り、それ以降は送りません（停止中の遅れ通知を防ぐため）。
- VAPID 鍵は初回起動で生成し、DB に保存します。連絡先は `.env` の `PUSH_SUBJECT`（既定は `SYOBOI_UA_URL`）。

## 運用

```bash
docker compose ps
curl -s http://127.0.0.1:8000/api/status; echo
docker compose up -d --build                             # 更新
sqlite3 data/anime.db ".backup backup-$(date +%F).db"    # バックアップ（要 sqlite3）
docker compose down                                      # 停止
sudo tailscale serve --https=443 off                     # serve の設定を外す
```

データは `./data/anime.db` にあります。取得中に停止すると、ログに「中断されました」と残り、次回の取得でやり直します。

## API（参考）

| メソッド | パス | 内容 |
|---|---|---|
| GET | `/api/status` | 取得状況 |
| POST | `/api/sync` | 取得開始（本文 `{start, end}` で期間指定） |
| POST | `/api/sync/cancel` | 取得の中断 |
| GET | `/api/logs` | 取得履歴 |
| GET | `/api/catalog` | 新作一覧 |
| GET/POST | `/api/tracks` | 登録作品の一覧（`?archived=true` で視聴済み）／登録 |
| PATCH/DELETE | `/api/tracks/{id}` | 作品の編集／解除 |
| POST | `/api/tracks/{id}/generate` | 予測話の作成 |
| POST | `/api/tracks/{id}/resync` | 取得データの再反映 |
| POST | `/api/tracks/{id}/archive` / `unarchive` | 視聴済みへ移す／登録作品へ戻す |
| GET/POST | `/api/tracks/{id}/episodes` | 話の一覧／追加 |
| PATCH/DELETE | `/api/episodes/{id}` | 話の編集／削除 |
| POST | `/api/episodes/{id}/revert` | 取得値に戻す |
| GET/POST | `/api/push/{key,settings,subscribe,unsubscribe,test}` | 通知の購読と設定 |
| GET | `/api/calendar?start=&end=` | 期間内の話 |
| GET | `/calendar.ics` | iCalendar |
